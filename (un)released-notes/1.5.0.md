### New Features
- Added support for gift events (currently exclusive to YouTube):
  - Default widget now shows gift alerts;
  - Emulator can dispatch gift events for testing;
- Implemented globally emulator events dispatch (to receive events emitted by the emulator in your OBS source for example);
  - All events dispatched by the emulator has a flag `unichat:emulator_generated` to identify them as emulator-generated events;
- Added warn messages to widgets;
- Added support for custom icons in scrapers (only `data:` URLs);
- Added MSI installer for Windows;

### Fixes and Improvements
- Updated icons and splash screen;
- Plugin kick moved to [`unichat-community/unichat-plugin-kick`](https://codeberg.org/unichat-community/unichat-plugin-kick);
- Removed author type `VIP` (detected with `unichat:raw:twitch:vip` flag);
- Fully refactored interface;
- Improved releases and third party licenses loading;
- Fixed gallery assets loading;
- Global shared emotes loads at init;
- Fixed loading of external images (emotes, avatars, etc.) with incomplete addresses;
- Fixed update check cache folder verification;
- Removed the example widget from the widget list;
- Renamed widget files:
  | Before      | Now           |
  |-------------|---------------|
  | `style.css` | `widget.css`  |
  | `main.html` | `widget.html` |
  | `script.js` | `widget.js`   |

### Other Changes
- Changed license from MPL-2.0 to EPL-2.0;
- Locked width and height of main window to `1024x576`;
- Moved docs to another repository;
- Fixed jsonrpc server error parsing;
- Added a content security policy to the application;
- The scraper webview button is now hidden behind a developer setting;
- Scrapers now always run in English on Windows, avoiding events being missed on systems with another language;
- Twitch scraper now blocks ad frames completely;
- Widgets that disconnect are now properly detected and cleaned up;
- Improved scrapers and plugins log identification;
- Restored the `switch` variant of `checkbox` fields in widgets;
- Removed mantine and all react stack, replaced by preact with tailwindcss and self implemented components.
- Replaced the internal web server and http client with lighter alternatives;
- Updated toolchains to:
  - `node` to `24.16.0`;
  - `pnpm` to `10.33.4`;
  - `rust` to `1.95.0`;
